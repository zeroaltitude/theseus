# tides

A small tide-table library for an invented harbour, Port Wenlow.

- `tides.py`: read a table of `HH:MM height` lines, find the high and low
  waters, and the tidal range.
- `test_tides.py`: its tests: `python3 -m unittest -v test_tides`.
- `slow_survey.py`: a survey of thirty stations that takes 90 seconds and
  prints its progress.
