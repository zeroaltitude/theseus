# The Theseus herdr plugin

Keys, a link handler and a startup hook for [herdr](https://herdr.dev), calling `theseus herdr ...`.
Link it once, as yourself: `theseus herdr plugin` prints the line. The operator's guide is
`docs/herdr.md`; `theseus herdr setup` prints the config (toasts, sidebar rows, keys) to go with it.
