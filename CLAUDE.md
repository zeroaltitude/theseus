@AGENTS.md

## Only for Claude Code

- Each directory with an `AGENTS.md` has a one-line `CLAUDE.md` that imports it, so Claude Code loads a directory's
  guide when it reads files there. Read the guide yourself before you edit in a directory whose files you haven't
  read yet.
- The gate runs longer than the Bash tool's default two-minute timeout. Give it a longer one, or run it in the
  background and read its log.
