## H7: NOT changed (needs the owner)
`request_digest` is deliberately taken before the tail: `own_bench/rebuild.rs` renders the first request from the compilation and nodes alone and accepts it only if its digest equals the recorded one ("taken before the recall, standing, task and wake views"). Recomputing after `tail_blocks` would make every replay of a turn with a pending wake, task view or standing-here line `NotRebuildable`. The overflow retry compares compile digests (both pre-tail), which is the right comparison; a post-tail digest would make it differ whenever a tail changes. So the retry was not affected. The real inconsistency is the other way: `route_step::apply_effort` recomputes `c.digest` over the request **including** the tail, so an effort-changed turn records a digest `rebuild_first` cannot reproduce (trim-effort's area). No test added for it; I did not prove that last point by running it.
