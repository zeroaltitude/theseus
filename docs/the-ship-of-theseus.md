# The Ship of Theseus

*The Ship of Theseus*, the design document, is in chapters since v0.80: start at **[spec/README.md](spec/README.md)**,
the index, which lists them in order. Each chapter is under about 150 KB, so it can be read whole.

The words are the same. This file held the whole document until v0.79. The chapters, each without its first line (its
own title), concatenated in the index's order, are the whole document byte for byte. Part I, the specification, is
chapters 2 to 6; Part II, the build plan, is chapter 7; and Part III, the record of what was built, is chapter 8 on.

This file stays as a pointer, since other files link to it.
