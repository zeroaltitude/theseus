# The features, one page each

One page per feature in [the README](../../README.md): what it is, how it works (with the files and the spec
section), what you see on each surface, the proof with its numbers and dates, the limits today, and what is coming,
labelled with its release. Every number on these pages is recomputed from the data files under
[benchmarks/](../benchmarks/README.md), never copied from an earlier page.

| # | Feature | In one line |
|---|---|---|
| 1 | [Durable tasks you can watch, answer and steer from anywhere](durable-tasks.md) | A durable state machine; kill and resume; questions on every surface; thousands held as records; a heartbeat that never calls a model |
| 2 | [Fast, as a contract](fast-as-a-contract.md) | Written budgets, and a gate that fails the commit |
| 3 | [Jev in the core](jev-in-the-core.md) | Small typed judgments steer every message: model, effort, labels, thread, persona |
| 4 | [Context compiled for each turn](compiled-context.md) | Layers, a budget, a manifest, and `theseus why` |
| 5 | [It remembers everything, across sessions and tools](memory-across-sessions.md) | Recall over one graph, with citations and imports |
| 6 | [It fixes itself, and tells you after](self-improvement.md) | The nightly loop, the revert, and the keel |
| 7 | [Many characters, one memory; separate lines of work](personas-and-threads.md) | Personas and threads |
| 8 | [It trusts its environment and keeps a true record](trusted-environment.md) | Notify, don't block; the raw record; removable labels; the China-origin floor (landing in 1.0.3) |
| 9 | [Coding at the level of the field](coding.md) | Terminal-Bench 2.0, with the cost regression named |

These pages change when a feature does. [The status page](../status.md) changes with every step.
