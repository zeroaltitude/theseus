# Theseus documentation

- `the-ship-of-theseus.md` — the living design document and the documentation. Part I specification, Part II build plan, Part III as built (one section per closed milestone, with a divergence table). When code and Part I disagree, Part III records it and one of them is fixed. The PDF is a rendering of the same file.
- `notes/` — research and design notes the spec drew on (hooks investigation and comparison, hooks design, event-driven execution review).

The markdown is the source of truth; regenerate the PDF after editing (marked → HTML → headless Chrome).
