The harbour board publishes a table of the high and low waters for every station along the coast, and the library in this project reads those tables, finds the turning points between neighbouring readings, and works out the range between the highest and the lowest water of the day, which the board shows in metres. It does so without any network access, from a plain text file of readings, one per line, so that a survey boat with no signal can still check its sums at sea before it comes back to port.
